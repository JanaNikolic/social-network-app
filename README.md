# Social Network Frontend
## Overview

This is a full-stack social media application where users can register, log in, create posts, like/dislike posts, send friend requests, and interact with other users. The application follows a modern tech stack and features authentication, real-time updates, and a clean UI.

## Features

- User Authentication (JWT-based login & registration)
- Create, Edit, and Delete Posts
- Like & Dislike Posts
- Friend Requests & Friend List Management
- User Profile Page with Personal Information & Posts
- User Search Functionality
- Profile Picture Updates
- Commenting on Posts

## Tech Stack

### Frontend:
- React.js
- TypeScript
- Material-UI (MUI)
